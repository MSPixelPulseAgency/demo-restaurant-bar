# Aurelia Restaurant & Bar — MSPixelPulse Demo

Premium responsive restaurant + bar website concept built with React and Vite.

## Live demo
https://aurelia-restaurant-bar.vercel.app

## Included pages
- Home
- About
- Menu
- Banquet Facility
- Catering
- Gallery
- Visiting Hours
- Online Booking
- Menu Kit
- Contact

## Stack
- React
- Vite
- React Router
- Lucide React
- Vanilla CSS

## Experience layer
- Cinematic restaurant video section with fallback poster
- Editorial image-led layouts
- Responsive desktop/tablet/mobile behavior
- CSS-first motion and hover polish
- Reduced-motion support
- Sticky mobile Call / Directions / Reserve actions

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
