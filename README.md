# Aurelia Restaurant & Bar — MSPixelPulse Demo

Premium responsive restaurant + bar website concept built with React and Vite.

## Included pages
- Home
- About
- Menu
- Banquet Facility
- Catering
- Gallery
- Visiting Hours
- Online Booking
- Menu Kit
- Contact

## Stack
- React
- Vite
- React Router
- Lucide React
- Vanilla CSS

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Important
This is a demo website. The Aurelia brand, menu, pricing, address, contact information, operating hours, testimonials and event details are placeholders until final client content is supplied.

Before coding, read `AGENTS.md` and `PROJECT_CONTEXT.md`.
