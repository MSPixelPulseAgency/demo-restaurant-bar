# Responsive + QA Agent

Treat responsive quality as a release blocker.

## Test widths
- 1440px
- 1280px
- 1024px
- 768px
- 430px
- 390px
- 375px

## Check every page
- No horizontal overflow.
- Header never crowds or clips.
- Mobile menu covers viewport and remains scrollable.
- Media crops keep important subject matter visible.
- Typography never becomes too large for narrow devices.
- Buttons remain touch-friendly and readable.
- Forms collapse cleanly to one column.
- Tables/hours remain legible without sideways scrolling.
- Gallery and menu filters remain usable.
- Footer stacks logically.
- Bottom mobile actions never cover essential content.

## Browser behavior
- Verify Chrome/Safari-safe video attributes: muted, autoplay, loop, playsInline.
- Confirm fallback poster when video cannot autoplay or load.
- Respect reduced-motion users.
